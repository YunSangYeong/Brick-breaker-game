# BRICK//BREAKER

레트로 아케이드 스타일의 벽돌깨기 게임입니다. 별도 패키지 설치 없이 브라우저에서 실행됩니다.

## 실행

이 디렉터리에서 `python3 -m http.server 8000`을 실행한 뒤 브라우저로 접속하거나, `index.html`을 직접 열어 주세요.

- 방향키 / A, D / 마우스 / 터치: 패들 이동
- Space: 시작 및 공 발사
- P: 일시정지 / 재개
- 화면 버튼: 재시작 및 효과음 전환

목숨은 3개이며 모든 벽돌을 깨면 다음 스테이지로 넘어갑니다. 최고 점수는 브라우저에 저장됩니다. 외부 글꼴을 사용할 수 없으면 기본 글꼴로 실행됩니다.

## 야간 색상과 랜덤 선물

형광 발광 대신 차분한 흙빛 벽돌과 청록색 패들을 사용합니다. 벽돌을 깨면 22% 확률로 선물꾸러미가 떨어집니다. 패들로 받아 획득하세요.

- W: 패들 확장, 12초
- S: 공 속도 30% 감소, 10초
- G: 보호막, 15초 동안 한 번의 추락 방지

같은 선물을 다시 받으면 시간이 갱신됩니다. 서로 다른 효과는 동시에 적용되며, 일시정지 중에는 효과 시간도 멈춥니다. 목숨을 잃거나 스테이지가 바뀌면 효과가 초기화됩니다.

검증: `node tests/game-smoke.cjs`
